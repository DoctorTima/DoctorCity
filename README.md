# DoctorCity

Город в Minecraft Pocket Edition, построенный в 2013–2014 годах и достраивавшийся до 2019 года. Модель собрана из файлов мира.

Страница `index.html`:

- 3D-модель города: день и ночь, вид под землёй, запечатанные хранилища;
- AR-модель для iPhone и iPad (`DoctorCity.usdz`);
- хронология запусков мира и даты построек;
- предложение по развитию старого города (версия 4) со сравнениями «сейчас / проект».

Сайт статический, сборка не нужна. Его можно открыть через GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
